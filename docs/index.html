Wynncraft Price Dashboard

This is the informational copy of the dashboard hosted on GitHub Pages. It does not perform live price lookups — that requires a local proxy holding an API key, which only runs on your own machine.

The interactive version runs locally via a small proxy that keeps your Wynnventory API key server-side. Clone the repo and run:

npm start

Then open http://localhost:8123.

No API key yet? Request one from the Wynnventory team (Discord: @Aruloci / @Sirop), or just use their own live site directly: wynnventory.com. In-game, the Wynntils + Wynnventory mods already show these prices as item tooltips while browsing the Trade Market — that remains the fastest way to check a price while actually trading.

This project does not place, execute, or automate any Trade Market actions. All trading happens by hand in the real Minecraft client — this only helps you look up prices faster.
